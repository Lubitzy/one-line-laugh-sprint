One original line about everyday life for make.fun's "One-Line Laugh Sprint" bounty: an alarm clock that files an HR complaint when asked for five more minutes — and now its owner owes it overtime.

## Run it

```sh
python3 main.py --out /output
```

This writes the line (99 characters, UTF-8, one line) to `/output/entry.txt`. Standard library only, no network, deterministic: two runs write identical bytes.
